# 漫画ミーム本誌初出 調査台帳

更新: 2026-11-08
用途: トップページ「今日は何の日？」用。DEAD INTERNET MUSEUMの終了サイト展示とは別。

## 判定規則
- **公開可**: セリフ・コマの登場話数、掲載号、実際の発売日を照合できたもの。
- **要原作照合**: 掲載号や発売日を確定できても、該当のセリフ・コマがその話に存在するか未確認のもの。
- **調査中**: 該当話数・掲載号を特定できていないもの。
- 雑誌の表記日付（号の日付・奥付）と実際の発売日は区別する。単行本発売日、アニメ放送日、ネット拡散時期も別項目。
- 公開日未確認の候補は data/internet-history.json に追加しない。

## 注意
2006年32号は表記日付2006-07-24だが、実際の発売日は2006-07-10。日付だけから『ツギハギ漂流作家』のセリフ初出を断定してはいけない。

## 追加検証メモ（2026-11-08）
- 『ツギハギ漂流作家』の台詞が最終話に登場するとの記述を、2015年のブログと2026年の質問投稿で確認。いずれも原作そのものではないため、公開可には昇格しない。https://www.tcg-bloglife.com/entry/2015/02/19/114956 ; https://detail.chiebukuro.yahoo.co.jp/qa/question_detail/q10328913755
- 『だが断る』の単行本内位置は『ハイウェイ・スター その③』とする二次解説を発見。アニメ第28話の放送日を原作初出日と混同しない。https://conorelmes.com/anime/jojo-daga-kotowaru/
- 『ツギハギ漂流作家』由来のセリフがルフィのものと誤認されたネット文化の記録は、2013年の用語解説および2014年のゲームでの使用を報じた記事で確認。漫画の初出日とネットでの再流通日は別のイベントとして扱う。https://netyougo.com/manga/9378.html ; https://blog.esuteru.com/archives/7594274.html

## 第162次監査（2026-11-08）
- 2006年7月13日付の『週刊少年ジャンプ32号』当時の読者感想で『ツギハギ漂流作家』最終話の当該セリフを直接引用。後年の回想だけに依存せず、同時代記録で掲載話とセリフを照合できたため、7月10日発売日のカレンダーイベントを追加。https://aiba.livedoor.biz/archives/50561871.html
- 号数照合は文化庁メディア芸術データベースを元にしたジャジャン研。https://www.jajanken.net/sakuhins/zPm81YV8ER
- 『DEATH NOTE』は全話の号数一覧を確認したが、『計画通り』の原作話数を未確定。日付を推測して追加しない。https://www.jajanken.net/sakuhins/QLm8jkY09P

## 第163次監査（2026-11-08）
- 『DEATH NOTE』の『計画通り』は原作page.53『悲鳴』。掲載誌は週刊少年ジャンプ2005年7号（誌面日付2005-01-31）。文化庁メディア芸術DB由来のジャジャン研・INDEXINDEXと、漫画ミーム解説で交差確認。実売日は未確認なので本番カレンダーへの追加を保留。https://www.jajanken.net/sakuhins/QLm8jkY09P ; https://indexindex.net/work.php?work_id=6958 ; https://dijitama.com/keikakudoori/
- 『だが断る』は二次解説に単行本41巻という記述がある一方、巻ごとのエピソード対応に疑義があり、前回台帳の『ハイウェイ・スター その③』特定を確定情報として扱わない。https://x333.blog54.fc2.com/blog-entry-6020.html

## 第164次監査（2026-11-08）
- 『DEATH NOTE』page.53『悲鳴』掲載の週刊少年ジャンプ2005年7号は**2005-01-17発売**。Death Note Wikiの雑誌号別一覧に「表記日2005-01-31／発売日2005-01-17」が別列で掲載。高崎市公開の原画展資料も「WJ 2005年第7号 page.53 悲鳴」を裏付ける。https://deathnote.fandom.com/wiki/Weekly_Shonen_Jump ; https://www.city.takasaki.gunma.jp/uploaded/attachment/15905.pdf
- 発売日資料は二次情報なので、後日当時の書店・出版社の一次記録が見つかれば差し替える。『だが断る』の初出日は引き続き保留。

## 第165次監査（2026-11-08）
- 『だが断る』を含む『ジョジョ』第386話『グっときたぜ！』（単行本で『ハイウェイ・スター その③』）は、週刊少年ジャンプ1994年46号、**1994-10-18発売**。JoJo WikiのIn Store Dateと号数、ジョジョ疑問スレの原作話数一覧を突合。https://jojowiki.com/DU_Chapter_121 ; https://wikiwiki.jp/jojo2ch/%E3%83%87%E3%83%BC%E3%82%BF/%E5%8F%8E%E9%8C%B2%E8%A9%B1%E4%B8%80%E8%A6%A7/part4-5
- 1995年3月は41巻の単行本発売時期。ネットの一部解説は1995年を本誌初出と誤認させるので区別。発売日情報は専門ファンDB由来で、出版社の一次発売記録が見つかれば追加照合する。

### データ品質メモ
- 『グラップラー刃牙』の炭酸抜きコーラ場面について『第1話』と『第107話』の相反する記述がある。出版社画像付きの紹介と2019年のセルフリメイク報道が第1話を支持するため、107話説を採用しない。
- 彼岸島の「丸太」については作品の象徴であることと、特定のセリフの初出話数・日付を区別する。
- いずれも原作初出日未確定のため、公開用JSONへの追加は保留。
